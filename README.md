# 📊 Product Data Exploration

## 📌 Project Overview
This project focuses on exploring and analyzing product data to understand product categories, brand performance, pricing patterns, and inventory quantities.

The dataset contains product details such as Product ID, Product Name, Brand Name, Price, Quantity, Category, Price Range, Day, Country Code, and Month.

## 🎯 Project Objectives
- Explore and understand the product dataset.
- Analyze product prices and quantities.
- Identify different product categories.
- Compare brand-wise product prices.
- Understand monthly product records.
- Categorize products based on price ranges.
- Identify useful business insights from the data.

## 📂 Dataset Description

| Column Name | Description |
|---|---|
| Product ID | Unique product identifier |
| Product Name | Name of the product |
| Brand Name | Product brand |
| Price ($) | Product price in dollars |
| Quantity | Available product quantity |
| Category | Product category |
| Price Range | Product price classification |
| Day | Day of the month |
| Country Code | Country identification |
| Month | Month of the record |

## 🔍 Exploratory Data Analysis (EDA)

The following analysis is performed:

1. Understand the dataset structure.
2. Check for missing and duplicate values.
3. Analyze product categories.
4. Explore brand-wise product distribution.
5. Identify high-price and standard-price products.
6. Analyze product quantities.
7. Explore monthly product records.
8. Compare product prices across categories.

## 📈 Key Insights

- Find the lowest-priced product.
- Determine the total number of products.
- Compare product quantities.

- Analyze brand-wise pricing.
